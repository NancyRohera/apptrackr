# AppTrackr

Started as a way to practice React while job hunting. Ended up being something I actually use every day to track my applications.

## What it does

You add a job application, move it across columns as things progress, and get a clear picture of where everything stands. It also flags applications you haven't heard back from in over 2 weeks.

- Kanban board — Applied → Screening → Interview → Offer → Rejected
- Stats at the top showing total applied, interviews, offers and response rate
- Color coded role badges — PM, Dev, Social Media, QA, Data/BA, AI/ML
- Highlights applications older than 14 days with a "Follow up?" reminder
- Search, filter by status, sort by date or name
- Track interview dates so nothing sneaks up on you
- Second preference role field for jobs that ask for multiple choices
- Application source tracking — LinkedIn, Rozee.pk, Indeed, etc
- Export everything to CSV
- Dark mode
- Form validation with duplicate application warnings

## Built with

React, Tailwind CSS, Node.js, Express, MongoDB Atlas

## Running locally

Frontend:
```bash
cd apptrackr
npm install
npm run dev
```

Backend:
```bash
cd backend
npm install
node server.js
```
